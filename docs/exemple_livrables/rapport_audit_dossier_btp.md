## 11. Méthode et lecture

- **Statuts** : corroboré (confirmé par un vérificateur, un pair indépendant ou un contrôle déterministe, sans réfutation) ; à vérifier (un seul agent) ; contesté (confirmations et réfutations) ; non résolu (désaccord persistant ou preuve jugée insuffisante) ; réfuté.
- **Gravité ≠ confiance** : la gravité mesure les conséquences si le constat est vrai ; la confiance mesure la solidité de la preuve. Un risque grave peu certain appelle une vérification rapide, pas un abandon.
- **Niveau de preuve** calculé automatiquement : contrôle déterministe, citation retrouvée mot pour mot dans la pièce, observation localisée, ou non étayé.
